  • git init – создаёт новый локальный репозиторий в текущей папке.
  • git add – добавляет изменения в индекс (подготовку к коммиту).
  • git commit -m "сообщение" – создаёт коммит с сохранением изменений.
  • git push – отправляет коммиты в удалённый репозиторий.
  • git pull – загружает изменения из удалённого репозитория и сливает с локальной веткой.
  • git clone – копирует удалённый репозиторий на локальный компьютер.
  • git status – показывает текущее состояние репозитория (изменения, не добавленные в коммит).
